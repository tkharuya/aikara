# AiKara 1.0.0 — 個人用 Android カラオケ

Android 11 以降。API キー、アカウント登録、専用サーバーは不要です。
YouTube の動画を公式プレーヤーで再生し、端末マイクで歌声の音程を検出します。
YouTube 音声の抽出・ダウンロードは実装していません。

## 最初に試す

1. `aikara-1.0.0-personal.apk` を Android にインストールします。
2. 有線または USB のイヤホンを接続します。Bluetooth も利用可能ですが遅延補正が必要な場合があります。
3. 最初の「音階トレーニング」で「歌い始める」を押し、マイクを許可します。
4. 緑のバーがお手本、紫の線が自分の声です。練習音源はアプリ用に合成したオリジナルの音階です。

## YouTube で歌う

- カラオケ・オフボーカル動画の URL を貼って「開く」を押します。
- YouTube アプリの共有先に AiKara を選んでも読み込めます。
- 動画の再生開始は上部のプレーヤーをタップする必要がある場合があります。
- 埋め込みが禁止された動画、削除・非公開動画などは利用できません。YouTube の広告・制限はそのまま適用されます。
- 動画は画面に表示したまま再生します。アプリがバックグラウンドになると再生とマイクを停止します。
- 原曲のボーカルを自動除去する機能はありません。歌入り動画では元の歌声も聞こえます。

## お手本バーの作成

「音源から推定」で、その曲の歌声が入った手持ち音源を選んでください。端末で再生可能な MP3、M4A、WAV などを Android のデコーダーで読み込みます。実際の対応形式は端末のデコーダーにも依存します。

解析方式は YIN による単旋律の音程推定です。ボーカルだけ、または単一楽器の旋律に適しています。伴奏や和音が入った完成済みの楽曲から、主旋律だけを正確に取り出す機能ではありません。その場合はベース、楽器、コーラスを拾うことがあります。解析結果には「自動推定」と表示します。

伴奏だけの音源には歌うべきメロディーが通常含まれません。伴奏の読み込みと、お手本用の歌声音源の読み込みは別操作です。YouTube URL だけからお手本バーは生成されません。

原曲と伴奏の前奏が違うときは「調整」→「お手本の開始位置」を調整します。正の値は、お手本全体を遅らせます。曲の途中でテンポが異なる音源同士は、開始位置だけでは合わせられません。

正確な音程データを持っている場合は JSON / CSV を「データ読込」で取り込めます。MIDI ファイルの直接読み込みには対応していません。

```json
{
  "format": "aikara-guide-v1",
  "title": "練習曲",
  "offset": 0,
  "notes": [
    {"start": 0.5, "end": 1.2, "midi": 60},
    {"start": 1.3, "end": 2.0, "midi": 62}
  ]
}
```

時間は秒、midi は MIDI ノート番号です。C4=60、A4=69。単旋律のみで、時間が重複する音符は読み込めません。CSV は `start,end,midi` を先頭行にしてください。

## 判定・練習

- 音程一致率は、計測したお手本区間のうち ±50 セント以内に入った割合です。1 半音は 100 セントです。
- マイクが ON で再生中のお手本区間のみを計測し、無音も不一致に含めます。マイク OFF の区間は計測されません。
- 約 50 ms 単位で、同じ再生位置を重複して採点しません。区間を歌い直して評価をやり直す場合は「音程一致率をリセット」を押してください。
- 「オクターブ違いを許容」が初期状態で ON です。厳密な高さで比較するときは OFF にしてください。
- 音量、抑揚、ビブラート、表現力は評価していません。市販カラオケの総合点とは別の指標です。
- 「マイク・再生の遅れ補正」は歌声の線を左へずらします。初期値 100 ms。端末・イヤホンに合わせて調整してください。
- キー変更は端末音源のみ。伴奏とお手本を同じ半音数だけ移調します。端末がピッチ変更に対応しない場合はエラーを表示します。YouTube のキー変更は非対応です。
- A / B を現在位置に設定すると区間を繰り返します。YouTube 側の広告やバッファリング中の挙動は実機確認が必要です。

## 保存とプライバシー

曲名、YouTube の動画 ID、音源の参照先、解析した音程データ、調整値はアプリ内に保存します。マイク音声は保存せず、外部へ送信しません。録音や外部の解析 API はありません。

端末音源はコピーせず、Android のファイル選択で許可された参照先から再生します。元ファイルの削除・移動や権限変更後は選び直してください。お手本解析用音源もサーバーへアップロードしません。

YouTube 動画の読み込み・再生時には Google に接続し、YouTube / Google の規約・プライバシーポリシーが適用されます。アプリから規約ページを開けます。

「曲ライブラリ」から曲とお手本を JSON に書き出せます。音源本体は含みません。アンインストールすると内部の曲データは消えます。

## 検証範囲

- Java の音程処理テスト 439 件。合成した単音・倍音・ノイズ付加音で最大誤差 4.404 セント。無音・DC・ノイズ・小音量も確認。
- 8 / 16 / 22.05 / 44.1 / 48 / 96 kHz の合成入力をリサンプリングし、582 フレームの音程を確認。
- URL 検証、音符境界、オクターブ、無音を含む判定、ファイル形式のコアテスト 35 件。
- Chromium で画面操作・保存・読み込み・削除・疑似入力など 28 件。320〜1000 px の幅で横はみ出しなし。
- APK のコンパイル、v3 署名、ZIP 整列を確認。

Android 実機およびエミュレーターでの実行は未実施です。実マイク、MediaCodec、MediaPlayer、YouTube 再生、ファイル選択、バックグラウンド停止、Bluetooth 遅延は実機で確認が必要です。ブラウザー画面テストではネイティブコールバックを模擬しており、実機動作の証明ではありません。

## ソースからビルド

標準的な Android Studio プロジェクト構成です。compile / target SDK 35、min SDK 30、Java 8、AGP 8.7.3。AndroidX など外部の実行時ライブラリーは使用していません。Gradle wrapper は同梱していません。

今回の APK は `tools/build.py` で、公式 Android SDK build-tools、SDK platform、ECJ を指定してビルドしています。

```sh
python3 tools/build.py \
  --build-tools /path/to/android-sdk/build-tools/35.0.0 \
  --android-jar /path/to/android-sdk/platforms/android-35/android.jar \
  --ecj /path/to/ecj.jar \
  --keystore /path/to/aikara.jks \
  --password-file /path/to/password.txt \
  --output /path/to/aikara.apk
```

署名のエイリアスは `aikara`。継続して上書き更新するには同じ署名鍵を使用してください。署名鍵はソースとは別のバックアップ ZIP に保存しています。

`tools/make_demo.py` で練習音源を再生成できます。テストコードは `tests/` にあります。画面テストは Playwright と Chromium が必要です。`CHROME_BIN` でブラウザー実行ファイルを指定できます。
