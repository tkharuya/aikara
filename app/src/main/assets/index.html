解析について

音源解析は単旋律の音程推定です。歌声だけの音源に適しており、伴奏・和音・コーラスが入った曲では誤検出します。ボーカル分離、YouTube 音声抽出、歌詞の自動取得は搭載していません。

マイク音声は保存・送信せず、音程を端末内で処理します。YouTube 利用時は Google に接続します。

QUICK START

音程を見ながら歌う

  1. YouTube の URL を開くか、端末の音源を選択。
  2. 「歌い始める」でマイクを許可。歌声の音程が表示されます。
  3. お手本も出す場合は「音源から推定」で歌声入りの手持ち音源を読み込み。
  4. 前奏の長さが違う場合は「調整」で開始位置を合わせます。

最初の音階トレーニングは、お手本付きですぐ試せます。YouTube の再生開始は、上部の動画をタップする必要がある場合があります。
